# Football Intelligence

A football analytics and scouting platform built to explore player performance, compare statistics, and discover talent through data.

## About the Project

Football Intelligence aims to make football data easier to explore and understand. The goal is to build a platform where users can analyse players, examine team performance, and identify promising football talent using statistical insights.

This project is being developed as a personal full-stack development and data analytics project.

## Current Features

- Dashboard with an overview of the platform
- Player Explorer page
- Search players by name
- Filter players by position and league
- Responsive layout for different screen sizes

**Note:** The current player list uses sample data for interface testing. Real football data integration is planned.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js and Express (planned)
- MongoDB (planned)
- Python and Pandas (planned)
- Chart.js (planned)


## Planned Features

- Real football data integration
- Player profiles and performance statistics
- Team analysis
- Player comparison
- Statistical visualisations
- Scouting system to identify underrated players

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/armanares/football-intelligence.git
   ```

2. Open the project folder in VS Code.
3. Open `frontend/index.html` in your browser.
